# FAQ Accordion 💜

A simple and colorful FAQ Accordion built using HTML, CSS,
and JavaScript.

## Features

- 8 frequently asked questions
- Expand and collapse answers
- Only one answer open at a time
- Smooth opening and closing animation
- Colorful and clean user interface
- Responsive design for mobile and desktop
- Accessible buttons with expanded-state information

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Click any question to view its answer.

## What I Learned

- Selecting HTML elements using JavaScript
- Handling click events with `addEventListener()`
- Adding and removing CSS classes
- Using `classList.contains()` and `classList.remove()`
- Updating button states dynamically
- Creating responsive layouts with CSS
